# SAMSE_inputfiles
These are the input files to running aMSE (haddonm) for the South Australia Harvest Strategy. The Harvest Strategy files are not publicly available and can be requested from South Australia Research and Development Institute - see paper authors.
These files are for the Fisheries Research journal paper "Testing empirical Harvest Strategies against the complex dynamics of an abalone fishery in South Australia". They are also the input files for the South Australian component of the FRDC report Dichmont, C.M., Haddon, M., Mundy, C.N., Burnell, O., and S. Mayfield. 2026. Drawing strength from each other: simulation testing of Australia’s abalone harvest strategies CDC, FRDC Final Report 2019‐118. 183 p. https://www.frdc.com.au/sites/default/files/products/2019-118-DLD.pdf

The Fisheries Research paper is still going through the review process.
