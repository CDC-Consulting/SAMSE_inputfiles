# SAMSE_inputfiles
Input files for the Fisheries Research journal paper "Testing empirical Harvest Strategies against the complex dynamics of an abalone fishery in South Australia".

This paper is still going through the review process. These are the input files to running aMSE (haddonm) for the South Australia Harvest Strategy. The Harvest Strategy files are not publicly available and can be requested from South Australia Research and Development Institute - see paper authors.
